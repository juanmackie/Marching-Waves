# V9.1 manual browser verification

Date: 2026-09-01

## Environment

- Served from `python -m http.server 8001` at `http://127.0.0.1:8001/`.
- Browser reported WebGPU available (`intel gen-12lp`) and initialized an 8-worker pool.
- No external runtime dependencies were used.

## Observations

- Uploaded a local JPEG (`497 x 416`) through the file input; the UI reported
  `Image loaded successfully` and enabled `Generate Artwork`.
- The header reported `GPU · WebGPU` and `ACTIVE (8 Workers)`.
- Generated a TSP artwork with GPU acceleration disabled to exercise the CPU
  fallback. The worker progress UI reported `TSP: 500 left...`, then the final
  view reported `Artwork generated (final view)` and `Complete!`; the canvas
  contained rendered pixels and SVG export became enabled.
- Exercised pause/resume controls during a TSP run: the controls toggled between
  `Pause` and `Resume` and the progress label changed to `Paused` before resume.
- Exercised cancellation during a TSP run while progress was active: the UI
  reported `Cancelling...`, then `Operation cancelled`, and export remained
  disabled for the cancelled run.
- Exercised SVG export after a successful run by intercepting the download blob:
  the export status was `SVG exported successfully!`; the blob was 116,211 bytes,
  contained a `<path>`, contained no `<script>`, and had a complete XML `<svg>`
  document (XML declaration precedes the root element).
- Browser console and page-error checks were empty after the run.

This is a local smoke check, not a claim of visual quality or physical accuracy.
